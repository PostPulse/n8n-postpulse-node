## Rules for filling in task files

In planning mode, save the planned sequence of actions in `backlog.md`. Save details of specific subtasks as separate files in the `./plan` subfolder. Copy the current task and its subtasks to the list of active tasks in `active.md` and mark them as completed there. After completing all subtasks from the `active.md` list, move them to the completed list `completed.md` (at the top of the list) and mark them as completed in `backlog.md`. 
After completing all work according to the plan from `backlog.md`, clear it for the next planning.
